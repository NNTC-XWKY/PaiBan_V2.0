# 排班管家（Windows 桌面版）

适用于约 20–50 名员工的餐饮、酒店排班工具。使用 Python 标准库 Tkinter 开发，无需安装第三方 Python 包即可运行源码。

## 功能

- **员工管理**：新增、编辑、停用、删除员工，维护岗位和用工类型。
- **班次设置**：自定义班次名称、起止时间及每班最低 / 最高人数。
- **两班倒 / 三班倒**：两班倒默认使用早班、夜班；三班倒默认使用前三个班次（通常为早、中、夜班）。
- **自动排班**：按自然月累计工时尽量均衡，加入适度随机性；尽量遵守默认 11 小时休息间隔，并避免同一员工同一天重复排班。
- **手动调整**：双击排班记录或选中后修改日期、班次、员工；支持删除记录。
- **同班人员**：排班表中显示同一天、同一班次的其他值班员工。
- **工时显示**：排班表显示本班工时和员工当月累计工时；跨午夜班次可正确计算。
- **工时统计**：按自然月汇总员工月工时、班次数及与在职员工平均工时差。
- **完整 CSV 导出**：导出与排班表界面一致的全部 9 列数据：日期、星期、班次、上班时间、本班工时、员工、岗位、其他值班员工、员工当月累计工时。文件使用 UTF-8 BOM，可用 Excel 打开。
- **本地保存**：数据保存在程序 / EXE 同目录的 `schedule_data.json`。

## UI 与小窗口适配

- 采用 **方案 C：左侧栏管理版**，软件名称为「排班管家」。
- 排班总览、员工管理、班次设置、工时统计使用统一的左侧导航和管理界面风格。
- 窗口可缩小至 760 × 540；各页面提供纵向滚动区域。
- 所有数据表均提供横向和纵向滚动条。窗口较窄时可横向滚动查看完整列，不会因列宽不足而丢失数据。
- 操作区分组排列，减少小窗口下控件挤压。

## 本机运行

需要 Python 3.10 或更高版本（Windows 安装包建议勾选 Add Python to PATH）。

```powershell
python 排班管理系统.py
```

Tkinter 通常随 Windows 官方 Python 安装包提供。`requirements.txt` 当前无第三方依赖。

## 上传 GitHub 并自动生成 EXE

1. 在 GitHub 新建一个空仓库。
2. 将本目录内所有文件和 `.github` 文件夹上传到仓库根目录（不要只上传 `.py`）。
3. 打开仓库的 **Actions** 页面，允许 Actions 运行。
4. 推送到 `main` / `master` 分支，或在 Actions 中手动运行 **Build Windows EXE**。
5. 工作流完成后，进入对应运行记录，在 Artifacts 下载 `RosterApp-Windows`，解压即可得到 `排班管家.exe`。

## 数据与备份

首次运行会在 EXE 同目录创建 `schedule_data.json`。更新 EXE 时请勿覆盖或删除该文件；建议定期备份。CSV 是导出副本，不会自动回写到系统。

> 排班算法会尽量均衡工时，但员工数量、班次最低人数、休息间隔和岗位实际需求可能互相冲突。生成后请人工检查班次人数及休息安排。当前自动排班以每班最低人数为目标，不会自动补足到最高人数。
